# Submit to the Chrome Web Store

Visibility: **Unlisted**. Only people with the link can install it.

The package is `store/praat-ai-kompak-werksbank-1.0.1-cws.zip`. `manifest.json` is at the root of the zip. Do not upload a different zip.

The display name in every language is exactly: **Praat.ai kompak werksbank**

## Steps

1. Open https://chrome.google.com/webstore/devconsole and sign in with the Google account that should own the extension.
2. Register as a Chrome Web Store developer. The fee is $5, once. Wait until the registration is accepted.
3. Click **New item** and upload `praat-ai-kompak-werksbank-1.0.1-cws.zip`.
4. Save the item. Do not publish it yet.
5. Under **Store listing**:
   - Primary language: Afrikaans. Paste the name, short summary and description from [listing.af.md](listing.af.md).
   - Add English and paste the matching fields from [listing.en.md](listing.en.md).
   - The name in both languages is exactly `Praat.ai kompak werksbank`.
   - Category: Productivity. If a subcategory is offered: Workflow & planning.
   - Upload the three screenshots in `store/screenshots/` (1280×800).
   - Upload `store/promo-440x280.png` as the small promo tile.
   - The 128×128 icon is already in the package.
6. Under **Privacy**:
   - Privacy policy: `https://github.com/GerrieGrotman/praat-ai-kompak-werksbank/blob/main/PRIVACY.md`
   - Choose that the extension does not collect or use user data.
   - Paste the single purpose, the storage reason, the host reason and “no remote code” from the listing file.
   - Confirm that nothing is downloaded from a server and executed.
7. Under **Distribution** or visibility: choose **Unlisted**.
8. Read the warnings. The host is only praat.ai and www.praat.ai. The only permission is storage.
9. Click **Submit for review**.

Review can take a few days. Do not change the package in the meantime, unless the store sends something back.
