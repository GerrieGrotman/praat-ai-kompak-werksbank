## Short summary (132 characters maximum)

Compacts the Praat.ai transcription workbench for a small laptop, with a large text box and no page scrolling.

## Detailed description

Praat.ai kompak werksbank fits the Praat.ai transcription workbench on a small laptop.

On the normal page the text box is too small and you have to scroll to listen and type. This extension hides the sidebar and the big headings, turns the audio player into a short strip, and gives the text box the rest of the screen. Play, time, speed, the note and the buttons (Report, Save, Submit) stay on screen. The waveform bars stay visible.

Compact mode is on after you install it. Turn it off or on from the extension icon, or with Alt+Shift+C. The choice is remembered on this computer.

It only runs on https://praat.ai/job/… It does not change your text and it does not send anything to a server.

The pictures show a stand-in of the job page, with the same layout as the real site.

This extension is unofficial. It is not affiliated with Praat, Solidariteit or AfriForum, and it is not made or endorsed by them.

## Privacy practices

Privacy policy URL:

### Do you collect or use user data?

No. Choose that the extension does not collect or use user data.

The only storage is a local on/off preference. It is not collected, transmitted, sold or shared. No personally identifiable information, health or financial data, authentication credentials, communications, location, web history or website content is read for any remote use.

### Permission: storage

The storage permission is used only to save the user’s on/off choice for compact mode (chrome.storage.local, key compactEnabled). The value stays on the device. It is not sent to a server.

### Host access: https://praat.ai/* and https://www.praat.ai/*

Host access is required so the content script can change the layout of the transcription job. The script does not read the transcript in order to transmit it, does not click Save or Submit, and does not run on any other site. A wildcard for every subdomain is not requested.

### Remote code

No. All JavaScript and CSS are in the package. Nothing is downloaded from a server and executed.
